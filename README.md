I designed a form that can be used by any Organization or Company to collect details of people
who showed interest and might want to apply for any vacant position within the 
organization or company. 
It can also be used to send message directly to the organization or company.
It has a section where you can upload your CV and also upload your passport.
The Form is highly responsive, meaning: It displays well on mobile phone, Tablets, 
laptops and desktops.

challenges i faced when designing the form and how i solved them.

challenge 1:
How to make the form accept CV.

How i solved it:
I used label tag , give it name "Upload CV." 
Made the input type to be file,and accept .pdf, .docs, etc.

challenge 2 :
How to make my "Submit" and" Clear" Button have a different behavior when
mouse comes on them.

How i solved it.
I used "wrapper button:hover{
background-color: yellow;
}
Now, when mouse comes ontop of them, the background changes to yellow.
That was how i achieved my desire.

Technologies used are only HTML and CSS.
